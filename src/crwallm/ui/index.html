모으기

주소를 붙여넣으면 그 페이지에 무엇이 있는지 보여드립니다.

이 화면은 무엇인가요?

한 페이지에서 반복되는 것을 표로 만들어 엑셀로 저장합니다. 상품 목록, 글 목록, 검색 결과처럼 같은 모양이 여러 번 나오는 페이지에서 가장 잘 됩니다.

결과는 이 화면에만 있습니다. 창을 닫으면 사라지고, 저장한 파일만 남습니다. 나중에 다시 꺼내보거나 오래 걸리는 크롤을 걸어두려면 작업 탭을 쓰세요.

상품 목록, 글 목록처럼 여러 개가 나열된 페이지가 가장 잘 됩니다.

이름은 미리 채워뒀습니다. 그대로 모으기를 누르셔도 되고, 마음에 안 들면 고치세요. 필요 없는 것은 이름을 지우면 모으지 않습니다.

이 화면은 무엇인가요?

크롤을 큐에 넣어두고 다른 일을 하는 곳입니다. 모으기와 달리 결과가 데이터베이스에 남아서, 창을 닫았다 열어도 그대로 있고 중간에 멈췄다 다시 돌릴 수 있습니다.

실제로 돌리는 것은 워커입니다. crwallm up이 함께 띄웁니다 — 워커가 없으면 작업이 대기에서 움직이지 않습니다.

레시피가 뭔가요?

한 사이트를 한 번 이해해 둔 것입니다. 무엇이 반복되고 그 안의 어느 조각이 제목이고 가격인지 적어둔 파일이고, recipes/ 폴더에 YAML로 삽니다.

만들 때는 모델이 한 번 도와줄 수 있지만, 만들고 나면 모델을 부르지 않습니다. 10만 페이지를 돌려도 0회입니다 — 이게 이 도구의 요점입니다.

동작 확인됨은 주장입니다. 옆의 숫자가 근거이고, 확인 버튼으로 지금도 맞는지 다시 재볼 수 있습니다. 사이트가 개편되면 여기서 먼저 드러납니다.

레시피

새로 만들려면 터미널에서 crwallm recipe adapt <이름> --url <주소> — 모델이 페이지를 보고 이름을 짓는 데 몇 분 걸리는 일이라 화면에는 두지 않았습니다.

뽑는 항목

이 화면은 무엇인가요?

문장으로 시키는 곳입니다. "이 주소에서 제목이랑 가격 뽑아줘" 처럼 말하면 모델이 페이지를 살펴보고, 레시피를 만들고, 크롤을 큐에 넣습니다.

각 단계가 카드로 보입니다 — 무엇을 왜 했는지 확인할 수 있고, 결과는 작업 탭에 남습니다. 모델(Ollama)이 필요합니다.

"https://quotes.toscrape.com/ 에서 명언이랑 작가 뽑아줘" 처럼 말해보세요.

여기서 무엇을 바꾸나요?

모델은 바로 바꿀 수 있습니다. 고르면 .env에 적히고, 이 창은 즉시, 워커는 다시 시작할 때 반영됩니다.

기본값은 이 브라우저에만 저장됩니다. 모으기와 작업 화면이 열릴 때 이 값으로 채워집니다.

서버 설정은 읽기 전용입니다. 주소·토큰·데이터베이스는 .env와 실행 인자가 정하고, 화면에서 고칠 수 있게 하면 지금 쓰고 있는 창을 스스로 잠글 수 있습니다.
